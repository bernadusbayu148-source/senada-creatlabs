# Kredensial dan lisensi foto — Senada Journey

Foto destinasi pada demo **Senada Journey** adalah foto lokasi nyata yang berasal dari Wikimedia Commons. Foto dirender pada kartu dengan pemotongan `object-fit: cover`; foto tidak membuktikan perjalanan/perjalanan paket benar-benar tersedia. Paket, tanggal, harga, nomor booking, dan operator **sepenuhnya fiktif**.

Foto ditautkan langsung ke thumbnail Wikimedia (lebar sekitar 960 piksel) untuk menghindari memasukkan file berukuran besar ke repositori. Foto kredit ditampilkan dalam kartu dan bagian **Kredit foto destinasi** di bagian bawah halaman, termasuk tautan sumber dan lisensi.

**Batasan:** Ketergantungan pada domain Wikimedia berarti foto mungkin tidak dapat dimuat jika jaringan/peramban memblokirnya. Saat itu, ilustrasi CSS lama tetap berfungsi sebagai *fallback*.
